# AWS Cost and Usage Report

> _AWS 비용·사용량 데이터를 가장 세밀한 수준(시간, 리소스, 태그 단위)으로 기록하는 원본 청구 데이터._

`여러 서비스의 비용이 어디서 발생했는지 근거 데이터를 만들어야 할 때  `
`부서/프로젝트별 비용 분배(Chargeback/Showback)가 필요한 경우  `
`Athena/QuickSight/Excel/BI 도구로 비용 분석 자동화할 때`

## AWS Budgets

> _지정한 비용 또는 사용량 한도를 초과하면 이메일/SNS 알림을 보내는 예산 관리 서비스._

`개발자 실습 계정에서 과금 폭주를 막고 싶을 때   월 단위 EC2 비용을 30달러 안으로 제한하고 싶을 때   예산 초과 시 Slack으로 자동 알림이 필요할 때`

# AWS Cost Explorer

> _기간별 비용 변화·서비스별 비용 비중·절감 가능 영역을 시각적으로 분석하는 서비스._

`이번 달에 왜 비용이 증가했는지 원인 분석할 때   어떤 리전/서비스가 가장 비용을 차지하는지 비교할 때   Savings Plans 또는 RI 적용 시 예상 절감 효과를 평가할 때`

# Amazon EC2 Spot Instances

> _남는 EC2 용량을 최대 90% 할인 가격으로 제공하는 변동형 인스턴스._

`ML 학습 / 데이터 처리 배치 / CI 빌드 같이 중단되어도 괜찮은 작업에서 비용 절감   Kubernetes 노드 중 일부를 Spot으로 구성해 운영 비용 최적화   짧게 돌고 끝나는 컴퓨팅 작업 비용 낮추기`
