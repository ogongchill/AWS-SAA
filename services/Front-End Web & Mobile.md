# AWS Amplify Studio

>_시각적 UI 편집과 데이터 모델링이 가능한 Amplify 확장 환경_

`- 프론트엔드 개발자가 Figma → UI → 배포까지 빠르게 하고 싶을 때 - 코드 없이(또는 최소 코드로) React/Next.js UI + 백엔드 연결 작업을 단축하고 싶을 때`

# Amazon Location Service

_지도, 경로, 위치 기반 기능을 애플리케이션에 쉽게 추가_

`- 지도 표시, 사용자 위치 추적, 지오펜싱 기능이 필요할 때 - Google Maps API 비용이 부담되거나, 보안/데이터 주권 관리가 중요한 B2B 서비스`

---

# Amazon Simple Email Service (SES)

>_대규모 이메일 송수신 플랫폼_

`- 회원가입 인증 메일, 비밀번호 재설정 메일 등 트랜잭션 이메일 발송 - 마케팅 뉴스레터, 대규모 이메일 캠페인 자동화`

---

# AWS Device Farm

_실제 모바일 디바이스에서 앱 테스트 자동화_

`- 안드로이드/아이폰 실물 디바이스 수백 종에서 UI 테스트가 필요한 경우 - QA 단계에서 기기별 호환성 문제를 빠르게 검증하고 싶을 때`

---

# AWS Amplify

>_웹/모바일 앱의 호스팅 + 인증 + 스토리지 + 배포를 통합 제공_

`- 프론트엔드 개발자가 백엔드 인프라 고민 없이 앱 출시 속도를 높이고 싶을 때 - Serverless + CI/CD + App Hosting을 한 번에 구성하고 싶을 때`

---

# AWS AppSync

>_완전관리형 GraphQL API 서비스 (실시간 구독 포함)_

`- 모바일/웹 클라이언트에서 데이터 요청을 단일 GraphQL 엔드포인트로 관리하고 싶을 때 - 실시간 데이터 업데이트(실시간 채팅, 대시보드 등)가 필요한 경우`

---

# Amazon API Gateway

>_REST 및 WebSocket API를 구축/운영/보안/요금 과금까지 관리하는 API 플랫폼_

`- 서버리스(Lambda) 기반 API 또는 마이크로서비스 API 게이트웨이 구축할 때 - 인증/버전 관리/요청 제한/도메인 관리 등 API 수명주기 전체를 운영해야 할 때`
