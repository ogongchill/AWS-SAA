#Analytics

# Automated data-prep for Amazon QuickSight Q

> _자연어 질의(“매출 추이 알려줘”)가 가능하도록 데이터 모델을 자동 준비해주는 기능._

`현업 사용자가 SQL 없이 자연어로 대시보드 질의할 수 있도록 데이터를 전처리해야 할 때 BI 팀이 반복적으로 만드는 분석 보고를 자동화하고 싶을 때`

---

# Amazon Kinesis

> _실시간 스트리밍 데이터(로그, 이벤트, 비디오 등)를 처리하고 분석하는 서비스._

`IoT 센서 데이터, 클릭스트림 로그, 액세스 로그 등을 실시간 처리하고 대응할 때 CloudWatch Logs → Kinesis → Lambda → DynamoDB 같은 실시간 파이프라인 구성할 때`

---

# Apache Spark support on Amazon Athena

> _서버리스 Athena 환경에서 Apache Spark를 즉시 실행해 대화형 분석을 수행._

`데이터 레이크(S3)에 저장된 데이터에 대해 Spark 세션 열어서 바로 분석할 때 EMR 클러스터를 따로 띄우지 않고 Spark 코드 하나로 빠르게 처리할 때`

---

# Amazon Q in QuickSight

> _QuickSight 내에서 생성형 BI 분석을 제공하는 자연어 분석 기능._

`"지난 분기 주요 비용 항목의 원인은?" → 대화형으로 분석 요약을 받고 싶을 때 보고서 작성 시간을 줄이고 의사결정 속도를 높이고 싶을 때`

---

# Amazon MSK Serverless

> _Apache Kafka 스트리밍을 운영 없이(serverless) 자동 확장으로 제공._

`Kafka 운영 인력 없이, 데이터 스트림 파이프라인을 빠르게 구축해야 할 때 트래픽 양이 변화가 크고, 비용을 과금량 기반으로 맞추고 싶을 때`

---

# Amazon DataZone

> _조직 내 여러 데이터 소스를 통합하고 메타데이터 카탈로그 및 거버넌스를 제공._

`여러 부서·팀이 데이터를 공유해야 하는데 권한/보안/카탈로그 체계를 통합해야 할 때 데이터 오너십과 승인 요청(WF)을 공식화해서 데이터 가시성을 확보할 때`

---

# AWS Clean Rooms

> _데이터를 직접 공유하지 않고도 여러 조직 간 합집합/교집합 분석을 수행._

`파트너/고객사/광고사 간 데이터 비교 분석은 필요하지만, 원본 데이터는 공유할 수 없을 때 프라이버시 보호 + 공동 분석이 동시에 필요할 때`

---

# Amazon Redshift

> _대규모 데이터 웨어하우스 분석을 위한 고성능 MPP 분석 엔진._

`BI 대시보드 / 리포트 / 분석 모델이 많은 환경에서 대량 SQL 쿼리 처리 필요할 때 데이터 레이크 + DWH 하이브리드 구조 구축할 때`

---

# Amazon OpenSearch Service

> _대규모 텍스트, 로그, 검색 데이터에 대한 검색·분석·시각화 플랫폼._

`애플리케이션 로그를 중앙화하여 Kibana(OpenSearch Dashboards)로 분석할 때 실시간 검색 엔진(예: 서비스 내 검색 기능)을 구축할 때`

---

# Amazon EMR

> _Hadoop/Spark 기반 데이터 처리 워크로드를 위한 관리형 클러스터 서비스._

`대규모 배치 처리, ML 학습 전 데이터 정제 등 고성능 분산 처리가 필요할 때 자체 Spark/Presto/Hive 워크로드를 운영해야 할 때`

---

# Amazon MSK (Managed Kafka)

> _Apache Kafka를 완전 관리형으로 운영할 수 있는 스트리밍 서비스._

`Kafka는 필요하지만 운영/업데이트/브로커 구성은 관리하기 싫을 때 실시간 이벤트 기반 아키텍처 구축할 때`

---

# Amazon QuickSight

> _서버리스 형태의 BI 시각화·대시보드 도구._

`임원/팀 대시보드를 웹으로 배포하고, 권한 기반 조회를 하고 싶을 때 Tableau/PowerBI 대비 비용 효율적인 SaaS BI가 필요할 때`

---

# Amazon FinSpace

> _금융 데이터 저장·정제·카탈로그·규정준수 기능을 제공하는 분석 플랫폼._

`트레이딩 로그/시세 데이터/거래 기록 등 금융 도메인 데이터 분석이 필요할 때 규제 준수 + 데이터 추적성(Lineage)이 요구될 때`

---

# AWS Glue

> _ETL/ELT 파이프라인, 크롤러, 트랜스포머 등을 서버리스로 제공._
> 
>**데이터를 자동으로 읽고(Extract) → 변환하고(Transform) → 옮겨주는(Load) 서버리스 데이터 파이프라인 서비스**

```
- 매일 쌓이는 로그/XML/JSON을 가공해서 분석용으로 S3에 저장할 때
- 데이터 파이프라인을 자동화할 때
- Redshift로 데이터 적재할 때
- Athena에서 분석하기 위한 데이터 정리할 때
```

---

# AWS Lake Formation

> _데이터 레이크 구축 및 권한 제어를 단일 제어지점에서 관리._

`조직 전체가 동일한 권한 정책으로 S3 데이터 레이크 접근해야 할 때 Redshift / Athena / Glue / EMR의 접근 권한을 하나로 통합하려 할 때`

---

# Amazon SageMaker

> _데이터 준비 → 학습 → 배포까지 ML 파이프라인을 통합 제공하는 ML 플랫폼._

`ML 모델을 실 서비스에 안정적으로 배포해야 할 때 전체 ML 수명주기(Feature Store → Training → Deployment)를 표준화하고 싶을 때`

---

# AWS Data Pipeline

>_정기적인 데이터 이동·변환 작업을 스케줄링/오케스트레이션하는 서비스_

`- 매일/매주/정해진 시간에 S3 ↔ RDS ↔ DynamoDB ↔ EMR 간 데이터 이동이 필요할 때 - 데이터 ETL 흐름을 자동화하고 싶을 때`

---

# Amazon Athena

>_S3에 저장된 데이터를 **서버 없이 SQL**로 바로 조회할 수 있는 분석 서비스_

`- 로그, CSV, Parquet 같은 데이터 레이크 형태 데이터를 바로 분석하고 싶을 때 - 분석용 인프라(Redshift, Hadoop) 없이 빠르게 쿼리하고 싶을 때`

---

# AWS Data Exchange

>_서드파티(외부 업체) 데이터를 클라우드에서 직접 구독·활용할 수 있는 마켓플레이스_

`- 산업 데이터(금융, 날씨, 지도, 시장지표 등)를 구매하여 모델/보고서에 활용하고 싶을 때 - 외부 데이터셋을 자동 업데이트 상태로 유지하고 싶을 때`

---

# Amazon CloudSearch

_완전관리형 검색(Search) 엔진 서비스_

>`- 텍스트 검색 기능을 빠르게 구현해야 할 때 (검색창, 제품검색, 문서검색 등) - Elasticsearch/OpenSearch 직접 운영이 부담될 때`
