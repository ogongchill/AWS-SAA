# EBS 스냅샷

- **스냅샷은 증분 백업**  
    → 이전 스냅샷과 달라진 블록만 저장됨.
- **여러 스냅샷이 동일한 블록을 공유할 수 있음**
- **한 스냅샷을 지운다고 해서 비용이 바로 줄어드는 게 아님**  
    → 그 스냅샷만 참조하던 블록만 삭제됨  
    → 다른 스냅샷에서 공유 중인 블록은 계속 남음.

1) **EBS 스냅샷 작동 방식**
- 증분 저장
- 동일 블록은 여러 스냅샷이 공유
- 삭제는 “해당 스냅샷만 단독으로 참조하던 블록”만 제거

 2) **스냅샷 수명 주기 (Lifecycle Manager)**
	- 규칙 기반으로 자동 백업/유지/삭제 정책 설정 가능  
	    예: 매일 1개 생성하고 30일 후 자동 삭제


 3) **빠른 스냅샷 복원 (Fast Snapshot Restore, FSR)**
	- 스냅샷에서 **볼륨을 생성한 직후**에도 **I/O 성능 Full로 사용 가능**
	- 평소에는 스냅샷에서 복원한 볼륨이 초기에는 느릴 수 있음 → FSR로 개선
	- 단, **FSR은 추가 비용 발생**

 4) **스냅샷 잠금 (Snapshot Lock)**
	- 스냅샷을 **삭제/수정으로부터 보호**
	- Ransomware, 실수 삭제 방지용

 5) **퍼블릭 액세스 차단**
	- 모든 계정에서 스냅샷 **퍼블릭 공유를 금지**할 수 있음 (보안 정책 차원)

 6) **Outposts 및 Local Zones 스냅샷**
	- 온프레미스 또는 로컬 리전에 있는 리소스도 스냅샷 저장 가능
	- 단, 저장 위치는 Outposts/Local Zone 로컬 스토리지 또는 S3
