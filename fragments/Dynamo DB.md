
#  **PITR(Point-in-Time Recovery)란?**

**DynamoDB 테이블을 자동으로 지속 백업**하여, **손상되기 전의 원하는 시점으로 테이블을 복원할 수 있는 기능**

- 백업은 **자동**
    
- 최대 **35일간**의 변경 이력 유지
    
- 복원 시 기존 테이블을 **덮어쓰지 않고 새 테이블로 복원** → 안전함
    

즉, **데이터 손실 / 실수 삭제 / 애플리케이션 버그**로 데이터를 망가뜨렸을 때:  
→ **손상되기 직전 시점으로 복원 → 트래픽을 새 테이블로 전환**
