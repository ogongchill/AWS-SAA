
# 비용 옵션

|옵션|특징|언젠가?|비용|
|---|---|---|---|
|**On-Demand**|약정 없음, 가장 유연|예측 불가 트래픽|💰💰💰💰|
|**Reserved Instance**|1~3년 약정, 최대 72% 절감|안정된 워크로드|💰💰|
|**Savings Plans**|시간당 금액 약정, 가장 유연한 할인|장기적 + 유연성 필요|💰|
|**Spot**|90% 저렴, 중단 가능|배치/비중요 작업|💰|
|**Dedicated Host**|전용 물리 서버|라이선스/보안 요구|💰💰💰|

# Instance Store

- **EC2 호스트 서버에 직접 연결된 로컬 NVMe/SSD/HDD 스토리지**
- **속도 매우 빠름** (EBS보다 낮은 레이턴시 / 높은 IOPS)
- **영구 저장 아님** → 인스턴스 중지·종료·호스트 장애 시 **데이터 사라짐**
- **스냅샷/백업 불가**, 크기 변경 불가
- **임시 데이터(캐시, 스크래치 공간, 빅데이터 워크로드)에 최적**
